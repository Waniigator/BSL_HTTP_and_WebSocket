## 📝 Project Description
This repository contains a personal portfolio landing page built and served using the **Bonezegei Scripting Language (BSL v1.3.3)** HTTP Web Server framework.

- **Tech Stack:** HTML5, CSS3, Bonezegei Scripting Language (BSL)

## 🛠️ Setup & Execution Steps

   ```bash
